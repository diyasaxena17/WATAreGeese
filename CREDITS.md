## WATIsGrass

Credit to Ricky Qin and the WATIsGrass contributors for the Waterloo bridge and tunnel routing project from which WATAreGeese is technically derived:

https://github.com/rickyqin005/WATIsGrass

The inherited codebase also identifies Manasva Katyal and Ricky Qin in the Cordova project metadata. That attribution has been preserved.

## WATAreGeese

WATAreGeese continues this open-source lineage as an unofficial community project focused on preserving useful Waterloo indoor-routing work while modernizing the user experience.
